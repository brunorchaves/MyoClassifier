# Papers — sEMG / HD-sEMG e controle de dedos/mão

Lista de leitura sobre o estado da arte em decodificação de sEMG para controle
de dedos e mão. Baixe os PDFs comprados/obtidos para esta pasta (ela é
ignorada pelo git — ver `.gitignore`).

Ordem de leitura sugerida: comece pelo review (panorama geral), depois o
paper da Nature (produto mais avançado hoje), e por fim os dois de
decomposição de unidades motoras do Farina (limite teórico do que se extrai
do sEMG de superfície).
